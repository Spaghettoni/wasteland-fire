## Story 001 regression (frozen code)

`unit.gd`, `player_drive_input.gd`, `chase_camera.gd`, `driving_toy.gd`, `driving_toy.tscn` and `motorbike.tscn` are byte-identical to the pre-story snapshot (sha256). `greybox_field.gd`/`.tscn` changed additively only (the `player_2_start` export and the `Player2Start` marker; `player_start` untouched at (0, 0, 20)). `drive_harness` `coast`, `walls`, `showcase` and `soak` produce line-for-line identical output against the snapshot and the current tree (`coast`: 24.000 m/s, 120 ticks, 2.000 s, drift 0.00000; `walls`: 8/8 targets, 0 pinned, 0 violations; `soak`: 3978.82 m, 0 violations). `driving_toy.tscn` launched directly, headless and windowed: 0 ERROR/WARNING lines.

**Story 001 AC-5 carried into the new scene (a defect found and fixed in fix round 2).** A `Control` root's `physics_interpolation_mode` is OFF by default and a `Node3D` inherits its parent's mode, so the first build drew both Units at the 60 Hz tick rate on the 120 Hz display while `is_physics_interpolated_and_enabled()` still read true. Measured windowed at 24 m/s: drawn Unit speed with `World` at INHERIT min 0.00, max 57.47, sd 24.197 (alternate frames stepping 0 m and 0.4 m); with `World` set ON (as shipped) min = max = mean = 24.00, sd 0.000; frame-to-frame centroid jitter of the drawn Unit against its camera 0.28 px mean (max 1.11 px) at INHERIT against 0.000–0.002 px as shipped. Fix: `physics_interpolation_mode = 1` on the `World` node of `split_screen.tscn`; the harness `layout` check `world_interpolation` reads the explicit modes up the tree (not `is_physics_interpolated_and_enabled()`) so a re-save cannot drop it silently. Both ChaseCameras set themselves OFF as before.

## Notes, gaps and decisions recorded here

- **Additions beyond the AC text, all recorded in the decision log:** a 4 px overlay divider (takes no layout space, so the views stay 640×720); per-Player Body colours as data (`src/gameplay/split_screen/data/player_{1,2}_body_material.tres`, blue (0.18, 0.42, 0.82) and red (0.78, 0.16, 0.14), the Nose keeps its cream); a second start marker on the field (`player_2_start`); `World.physics_interpolation_mode = ON` (the regression fix above); and the two tools under `tools/evidence/`.
- **Head-on start.** Both Units start in the same lane, 40 m apart, facing each other; two Players who both hold throttle from the first second meet nose to nose at z = 0 after about 1.6 s and, as kinematic bodies, stop dead against each other with 24 m/s still commanded until one reverses (the prototype recorded the same head-on stop). That follows the fixed design for this story; Story 003 replaces the markers with the two Bases, which is where the start layout is decided. The harness scenarios `isolation` and `simultaneous` therefore teleport the Units into two corridors (x = −10 and x = +10) so the straight phases cannot collide.
- **Resolution above 1280×720** is upscaled, see the table above. Not a defect at this story's AC; a Game-Night Build decision.
- **`--disable-vsync` does not uncap the frame rate** on this Mac's built-in display, and `viewport_get_measured_render_time_gpu` returns 0.000 on Metal, so uncapped fps and per-viewport GPU time are not measurable here; the load-scaling numbers under AC-7 stand in. Story 001's "436 fps with vsync off" was a different probe and is not reproducible with the harness.
- **Audio:** neither SubViewport enables `audio_listener_enable_3d`; on 4.7 only viewports that do are merged for 3D audio (`docs/engine-reference/godot/modules/audio.md`). Irrelevant until sound arrives.
- **Window focus loss** while the harness holds injected keys was neither confirmed nor refuted to release them (a real OS focus loss cannot be triggered safely unattended); windowed runs launched from the CLI reported `focused=false` throughout and the injected keys still drove both Units.
- **Standards findings resolved after the workflow:** the `split_screen.gd` class doc was trimmed (doc/code ratio 2.60 → 1.63) and its measured claims now point here; the ghosting tool's over-complex self-test function was split into three helpers and its column headings are now read from the Input Map (screenshot 06 shows "Up Left Down Right", not a typed label); the harness's size is registered as **TD-003** and TD-001's trigger was amended; the self-test and the styled page of the ghosting tool are kept (decision log).
- **Importer sidecars.** `godot --import` wrote six `.png.import` files beside the retained Story 001 screenshots. They were importer output, not authored work, and were deleted with the developer's approval at `/story-done` (2026-09-30; the PNGs are untouched); `production/qa/evidence/.gdignore` now stops Godot importing evidence images, so none were written for this story's frames.
- **Out of this changeset:** `assets/art/**` (separate work).
